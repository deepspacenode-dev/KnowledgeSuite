# Drv Knowledge Suite V2.0.3 变更说明

发布日期：2026-09-08

V2.0.3 是基于 V2.0.2 P2 章节审核基线的完整升级，不新增破坏性数据库迁移，不覆盖 BookStack 正文、附件、用户或权限数据。

## B 端治理与界面

- 质量问题、RAG 状态和审核单元优先显示文件名/页面名，不再只显示内部序号。
- 质量问题页和章节审核页增加“查看原文/查看章节原文”，直接打开对应 BookStack 文章。
- 审批页增加“一键入库 RAGFlow”；仅当审核单元内全部 Wiki 页已审批且通过门禁时可用，后端逐页幂等发布并返回中文结果。
- 知识资产增加受控删除；知识缺口增加管理员删除、必填原因和 `gap.deleted` 审计记录。
- 质量页增加中文门禁帮助，明确扣分项、最终阻断原因和修复操作。
- 芯片手册继续按章节作为最小审核单元，避免大量散页审核。
- 治理中心和悬浮助手提供 RAGFlow 入口，默认目标为 `http://10.222.120.25/`。
- 移除 Bloub/GrokBot 点击后的蓝色虚线焦点圈，保留键盘可访问焦点效果。

## RAGFlow 官方 Widget 与 Chat

- 悬浮小人保留为交互入口，对话主体改为延迟加载的 RAGFlow 官方 Widget iframe，不再维护自研 Markdown/引用/会话渲染器。
- Widget 只允许 HTTP/HTTPS 主机和白名单路径，默认 `RAGFLOW_WIDGET_PATH=/chats/widget`，兼容 `/next-chats/widget`。
- 默认不授予麦克风/摄像头；只有显式设置 `RAGFLOW_WIDGET_ALLOW_MEDIA=true` 才开启。
- 提供 `contracts/ragflow/chat-assistant.v2.json`、`tools/ragflow/apply_chat_profile.py` 和 `tools/ragflow/check_widget.py`，支持脱敏 diff、dry-run、幂等应用和 Widget 可用性检查。
- Chat V2 Profile 采用保守阈值，Prompt 明确禁止把不同领域、芯片或平台证据混合为同一结论。

## A 端 Recall V4

- 增加任务类型阈值、最低分数和 Top1/Top2 差值门禁。
- 网络问题显式排除 Sensor/ISP/Camera/Video 候选；已知芯片不同时永不回收。
- 元数据不完整的旧文档只在严格结果少于 3 条时作为降级候选。
- 增加 `ok` / `no_match` / `ambiguous_match` 答案状态和脱敏 `recall-v4` trace，记录被拒绝候选及原因，不保存完整 chunk 正文。
- 新增 `kb feedback`，支持 `relevant` / `irrelevant` / `missing_answer` / `bad_link`；其中不相关和缺少答案会生成本地知识缺口事件。
- 回归集扩展至 12 条，增加禁止模块和预期答案状态检查。

## 兼容性

- Contracts V2 Schema 未做破坏性修改，与 `>=2.0.0 <2.1.0` 继续兼容。
- A 与 B 仍可独立部署，整套交付使用固定 `2.0.3` 镜像 tag 和制品 SHA-256。
